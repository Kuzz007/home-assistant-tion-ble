# Tion BLE для Home Assistant

Пользовательская интеграция для локального управления бризером **Tion Lite**
по Bluetooth Low Energy. Облако и базовая станция MagicAir не требуются.

> Проект находится на ранней стадии. Перед установкой убедитесь, что можете
> управлять бризером через приложение Tion Remote и знаете его MAC-адрес.

## Что поддерживается

- включение и выключение бризера;
- все 6 скоростей вентиляции;
- включение нагрева и выбор целевой температуры;
- включение подсветки и звуковых сигналов;
- температура наружного и приточного воздуха;
- ресурс фильтра и предупреждение о необходимости замены;
- диагностические датчики времени работы, объёма воздуха, мощности нагрева и
  кода ошибок;
- несколько бризеров: каждый Tion Lite добавляется отдельно по MAC-адресу.

Интеграция предназначена для **Tion Lite с Bluetooth**. Комплектация Lite Eco
без Bluetooth не поддерживается. Для стабильной связи рекомендуется прошивка
бризера не ниже `0570`.

## Подготовка Bluetooth в Proxmox

Home Assistant должен получить Bluetooth-адаптер целиком. Наличие Bluetooth на
самом сервере Proxmox ещё не означает, что он доступен виртуальной машине.

1. В Proxmox откройте виртуальную машину Home Assistant.
2. Откройте **Hardware → Add → USB Device**.
3. Выберите Bluetooth-адаптер. Предпочтительно привязать его по
   **Vendor/Device ID**, чтобы настройка сохранилась после перезагрузки.
4. Запустите или перезапустите виртуальную машину.
5. В Home Assistant откройте **Настройки → Устройства и службы**.
6. Проверьте, что интеграция **Bluetooth** установлена и показывает адаптер.

Для большого расстояния или толстых стен можно позднее добавить ESPHome
Bluetooth Proxy рядом с бризером. Интеграция использует штатную Bluetooth-систему
Home Assistant и сможет работать через такой прокси без изменения сущностей.

## Установка через HACS

Пока репозиторий не добавлен в стандартный каталог HACS, установите его как
пользовательский:

1. Откройте **HACS → Интеграции**.
2. Нажмите меню с тремя точками в правом верхнем углу.
3. Выберите **Пользовательские репозитории**.
4. Вставьте адрес:
   `https://github.com/Kuzz007/home-assistant-tion-ble`.
5. В поле типа выберите **Интеграция** и нажмите **Добавить**.
6. Найдите **Tion BLE**, откройте его и нажмите **Скачать**.
7. Полностью перезапустите Home Assistant:
   **Настройки → Система → Перезапустить Home Assistant**.

## Добавление первого Tion Lite

1. Полностью закройте приложение **Tion Remote** на телефоне. Оно не должно
   удерживать Bluetooth-соединение с бризером.
2. Переведите Tion Lite в режим **Ожидание**. В этом режиме индикация жёлтая.
3. Удерживайте **5 секунд** кнопку **Нагрев/Сопряжение** на корпусе. Бризер
   подаст два звуковых сигнала и перейдёт в режим сопряжения.
4. В Home Assistant откройте
   **Настройки → Устройства и службы → Добавить интеграцию**.
5. Найдите **Tion BLE**.
6. Дождитесь окончания 10-секундного сканирования Bluetooth.
7. Если бризер найден, Home Assistant покажет количество устройств. Нажмите
   **Выбрать найденный бризер**.
8. Выберите Tion Lite в списке. Рядом с каждым устройством показаны имя, MAC-адрес и
   уровень сигнала `RSSI`: например, `-45 dBm` — сильный сигнал, а `-90 dBm` — слабый.
9. Если нужного бризера нет, вернитесь к результатам и нажмите **Повторить поиск**.
10. Если поиск снова ничего не нашёл, выберите **Ввести MAC-адрес вручную**. Введите
    адрес из Tion Remote в формате `AA:BB:CC:DD:EE:FF`.
11. Переведите выбранный бризер в режим сопряжения по подсказке на экране, нажмите
    **Отправить** и дождитесь проверки соединения. Появится отдельный экран прогресса;
    не закрывайте его. Сначала Home Assistant создаёт системное Bluetooth-сопряжение —
    в этот момент бризер подаст звуковой сигнал. Затем интеграция отключится, подождёт
    3 секунды, подключится заново и прочитает состояние бризера. Сам по себе звуковой
    сигнал ещё не означает, что чтение данных уже завершено.

Сам список найденных устройств подтверждает, что Bluetooth Home Assistant видит
бризер. Если устройство есть в списке, но проверка соединения завершается ошибкой,
проблема уже не в обнаружении, а в сопряжении или обмене данными.

После добавления можно снова пользоваться Tion Remote. Интеграция подключается
к бризеру только во время опроса или отправки команды, а затем освобождает
Bluetooth-соединение. Если команда с телефона не проходит, дождитесь несколько
секунд и повторите её.

## Добавление второго бризера

Повторите предыдущие шаги для второго Tion Lite. Включайте режим сопряжения
только на том бризере, который добавляете сейчас. Home Assistant создаст для
каждого MAC-адреса отдельное устройство и отдельный набор сущностей.

Устройства можно переименовать после добавления:
**Настройки → Устройства и службы → Tion BLE → Устройства → Tion Lite → карандаш**.

## Если бризер не находится или недоступен

Проверяйте по порядку:

1. Bluetooth-адаптер передан из Proxmox в виртуальную машину Home Assistant.
2. Интеграция Bluetooth в Home Assistant видит адаптер без ошибок.
3. Бризер включён в сеть и находится достаточно близко к адаптеру.
4. Tion Remote на телефоне полностью закрыт, а пульт управления находится в
   спящем режиме.
5. Tion Lite переведён в режим ожидания, после чего кнопка
   **Нагрев/Сопряжение** удерживалась 5 секунд.
6. MAC-адрес введён без ошибок.

После неудачной попытки снова включите режим сопряжения и повторите добавление.
Если связь нестабильна, используйте USB-удлинитель для Bluetooth-адаптера или
установите ESPHome Bluetooth Proxy ближе к бризеру.

Если бризер подал звуковой сигнал, но подключение не завершилось, это означает,
что физическое BLE-соединение состоялось, а ошибка возникла позже — при системном
сопряжении, повторном подключении, подписке на уведомления или чтении состояния.
Начиная с версии `0.3.1`, интеграция сразу просит BlueZ выполнить операцию `Pair`,
не занимая режим сопряжения предварительным обычным подключением. После успешного
создания системной пары соединение закрывается, выдерживается пауза 3 секунды,
создаётся новое соединение и начинается обмен протокольными пакетами. Каждый этап
ограничен тайм-аутом, поэтому экран подключения не должен вращаться бесконечно:
вместо этого будет показана техническая причина и кнопка повторной попытки.

Начиная с версии `0.1.1`, подробная причина неудачного подключения записывается
в журнал Home Assistant. Сразу после ошибки откройте **Настройки → Система →
Журналы** и найдите `tion_ble`. Через аддон Terminal можно выполнить:

```bash
ha core logs | grep -Ei 'tion_ble|tion|bleak|bluetooth'
```

## Обновление

1. Откройте **HACS → Интеграции → Tion BLE**.
2. Если доступна новая версия, нажмите **Скачать**.
3. Перезапустите Home Assistant.

Удалять и заново добавлять уже настроенные бризеры при обычном обновлении не
нужно.
